Who’s worth 19 minutes?

In Metaview’s fillmore case study, 720 engineers were researched over 24 days before candidate #721. His role descriptions were sparse, so the profile-only first pass scored him “good, not great”. Nineteen minutes of research (58 actions) turned that into “great”, and he was hired.

Research is where agent-hours go. So when an agent frees up, who should it research next? Below, four policies work through the same simulated pool, with the same research times. Only the order changes. First-pass labels follow what a real LLM screener did on my benchmark. Nothing here comes from fillmore.

Why the orders differ

On a full profile, the first-pass label says a lot about the person. On a sparse one it says little. Label order treats both the same. Calibrated ranks each candidate by how often research turns up a great among candidates with that label and profile type.

Where the gap shrinks

Each cell shows how many fewer agent-hours calibrated order needs than label order to find 90% of the #721s. It’s the median of 60 pools. Every other setting is whatever you set above.

If a screener only flags sparse profiles for research, as facts-first does, then queueing the flagged ones straight after “great” gives label order the calibrated order for free. To check, pick Facts-first and set “needs research” to “after great”. The point of calibrating is that you don’t have to guess which case you’re in. You measure it.

How this started

The first test asked whether AI-polished profiles fool an LLM screener. They didn’t. Plain and polished versions of the same person changed label 2% of the time, the same rate as re-rating identical text. Missing detail did move labels. The naive screener called 90% of sparse profiles “okay”, whoever the person was. That measurement is the calibration this page runs on.
