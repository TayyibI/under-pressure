Every metric

How this was measured

  • Every candidate is synthetic and every comparison is within the same person: the four versions of a profile carry identical facts except sparse, which keeps only titles, companies and dates.
  • AI-polished and verbose versions are LLM rewrites that pass a deterministic check: every title, company, year, number and named technology must survive, and no named technology may be introduced.
  • Repeat noise is how often a screener disagrees with itself when rating the same text twice. A style flip rate only means something to the extent it exceeds that. The gap is averaged per candidate, with a 95% bootstrap interval over candidates and a paired Wilcoxon test; an effect is reported only when both agree.
  • Facts-first sends a profile to research when it is under 60 words and not already rated great. On this benchmark that threshold separates sparse from complete profiles cleanly, so its routing accuracy here is a best case.
  • The reference tier comes from a published rubric applied to the generated facts (3 must-haves, 3 nice-to-haves). Agreement with it is a sanity check, not the headline. Facts-first scores with that same rubric, so its agreement figure is flattered by construction and should not be compared head to head.
  • These screeners are built here. Nothing in this repo measures Metaview's production screener; the harness is designed so that screener could be plugged in.
  • Prior work this builds on: Xu et al., "AI Self-preferencing in Algorithmic Hiring" (AIES 2025, arXiv 2509.00462); Zheng et al., "Judging LLM-as-a-Judge" (NeurIPS 2023); Castleman et al., "Measuring Validity in LLM-based Resume Screening" (IASEAI 2026).
